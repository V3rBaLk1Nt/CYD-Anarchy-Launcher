# CYD Anarchy Launcher

A custom launcher for the Cheap Yellow Display (CYD 2.4" ESP32-2432S028).

## Status

Early stage. No launcher code written yet — this repo is the starting point.

## What's planned

- Touch-first home screen and app grid for the CYD
- Modular app system (apps as interchangeable modules)
- WiFi, Bluetooth, and SD card tools as built-in apps
- Red team / blue team tooling (not implemented yet)
- Theme support and visual redesign under active development

## Hardware

- Board: ESP32-2432S028 (Cheap Yellow Display)
- Display: 2.4" 240x320 resistive touch
- Storage: microSD + flash
